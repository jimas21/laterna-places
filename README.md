# Laterna Places

The places you can watch from in [Laterna](https://github.com/jimas21/laterna), the media player for the Steam Frame.

Laterna installs these for you. You don't need to download anything from here.

## Places

| Place | What it is | Size |
|---|---|---|
| **Cinema** | A small, elegant screening room with velvet seats. Comes with Laterna. | 7.8 MB |

Each place is on the [Releases](https://github.com/jimas21/laterna-places/releases) page. Laterna checks every download against a fingerprint it already knows, so it only ever loads the official files.
